## 👋 About Me

I'm **Renz**, a full-stack developer based in **Pandacan, Manila**, focused on building web applications that are fast, secure, and genuinely pleasant to use. I graduated **Cum Laude** with a **BSIT** degree from **Universidad De Manila**, and I hold **CSC Professional Level II** eligibility along with multiple **TESDA certifications**.

My day-to-day work spans the full stack — from designing Laravel backends and REST APIs, to building interactive front-ends in **Vue.js** and **Next.js** with strict **TypeScript**. I care about three things in every project I touch: clean architecture, security-first thinking, and interfaces that never feel like an afterthought.

Whether it's a corporate project management system, a webinar hosting platform, or my own portfolio, I treat every UI detail — spacing, motion, color, hierarchy — as part of the engineering, not decoration bolted on at the end.

<br/>

**A few things that describe how I work:**

- I design the database schema and API contract before touching a single component.
- I default to TypeScript on new front-end work, even on smaller projects, because the long-term clarity is worth the setup cost.
- I treat security as a feature, not a checklist item added at the end — rate limiting, sanitization, and access control go in from day one.
- I'd rather rebuild a UI from scratch than patch something that no longer matches the product's direction — which is why my own portfolio has gone through multiple full redesigns.
- I read every line of generated or scaffolded code before shipping it; nothing goes to production that I don't understand.

## 🎨 Design Philosophy

I don't treat design as a final layer applied over working code — it's part of the specification from the start. A few principles I keep coming back to:

- **Hierarchy first.** Every screen should make it obvious, at a glance, what matters most. If everything is emphasized, nothing is.
- **Motion with purpose.** Animation should clarify state changes — a hover, a load, a transition — not distract from them. If it doesn't earn its place, it doesn't ship.
- **Consistency over novelty.** A design system with a handful of well-chosen colors and spacing rules beats a page full of one-off styles, even if the one-offs look interesting individually.
- **Real content, always.** Lorem ipsum and placeholder avatars hide layout problems until it's too late. I build with real copy and real data from day one whenever possible.
- **Accessibility isn't optional.** Color contrast, focus states, and keyboard navigation are part of "done," not a follow-up ticket.
