## About

I'm a Full-Stack Web Developer focused on turning business requirements into reliable, maintainable, and user-friendly web applications. My main development focus is Laravel and Vue.js, with additional experience across Next.js and TypeScript — covering frontend, backend, database design, and overall application workflow.

Beyond building new features, I enjoy improving existing systems: clearer interfaces, simpler workflows, and more pleasant applications to use.

- 🎓 BSIT graduate (Cum Laude), Universidad De Manila
- 📜 CSC Professional Level II eligible · multiple TESDA certifications
